# КОСМОС - Шаурма • Кафе

Статичний вебсайт-меню для кафе "КОСМОС" у місті Житомир. 
Створено спеціально для розміщення на GitHub Pages. 

## Особливості
- **Cosmos Theme:** Темний фон, неонові акценти (magenta, cyan, yellow).
- **Mobile First:** Адаптивний дизайн, зручне мобільне меню та кошик.
- **Без залежностей:** Тільки чисті HTML, CSS та JS (Vanilla). Без фреймворків, без етапу збірки.
- **Доступність (A11y):** Семантична розмітка, підтримка клавіатури, стилі фокусування, reduced-motion.
- **Демо-кошик:** Повноцінний клієнтський кошик із фільтрацією товарів, підрахунком вартості та формою замовлення (демонстраційний режим, дані не надсилаються на сервер).

## Файлова структура
- `index.html` — головна сторінка з семантичною розміткою та вбудованим каталогом.
- `styles.css` — стилі, змінні, медіа-запити.
- `script.js` — логіка кошика, пошуку, фільтрації та модальних вікон.
- `README.md` — опис проєкту.
- `assets/food-platter.webp`, `assets/pizza.webp`, `assets/entrance.webp` — локальні фотографії закладу та страв.
